# Hi, my name is Esprits!
**I've always wanted to make my own mods since I was a kid playing this game and trying other people's mods. So here I am, with my own mod being finally published online.**

## So what exactly are the features?
I'm glad you asked! The mod will be pretty straightforward: I will be adding features that I think should be in the base game. Essentially, you can consider this a vanilla-like mod coming straight from my brain (and personal experiences playing the game). The features will range from simple things, like tree bark and wooden armour, to more complex features like full-fledged mobs.

## Of all mods, why should I try this one specifically?
If you're looking for an in-between of vanilla and modded, this mod is (probably) for you! My mindset with this project is for the features to be as close as possible as to what Mojang would add in the game. So, it will be keeping the vanilla spirit.
